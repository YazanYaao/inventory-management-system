Category Creation Guidelines
Organization Tips
  • Choose broad, inclusive names (e.g., "Office Equipment" instead of just "Pens").
  • Avoid duplicate names to ensure reporting accuracy.
  • You can reassign products to different categories later if needed.
Technical Info
  • Categories serve as the primary filter for the inventory directory.
  • A category cannot be deleted if it contains active products.
  • Category descriptions are for administrative use only.
